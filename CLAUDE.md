# CLAUDE.md

`agentkit` — общая библиотека примитивов агентов владельца (README). Код и комментарии на английском, README и
решения — на русском; комментарий объясняет, почему выбор лучше альтернативы.

- Ядро (`redact`, `safefs`) — только stdlib и Python 3.9: его копии работают на `/usr/bin/python3` хоста и в боксе
  hermes-dev. Аннотации пишутся как `X | None` под `from __future__ import annotations` (не вычисляются).
  `tests/test_stdlib_core.py` держит оба правила.
- Модули не импортируют друг друга: копия одного модуля не тянет другой.
- Пороги и маска — параметры, не константы потребителя: потребитель передаёт свой порог, маска одна (`MASK`).
- Изменение поведения — новый тег (`vX.Y.Z`); теги и push делает владелец или контроллер, не сессия.
- Проверки: `uv run pytest -q`, `uv run ruff check`.
